Welcome to fatalchat, a minimal, temporary, encrypted chat.

A room is just a link. Start one, send the link to a friend, and talk.

The link ends in a secret key after the # sign. Your browser encrypts every message with that key before it leaves, and the browser never sends the part after the # to the server.

The server only ever holds ciphertext, so it cannot read a room, and there are no room lists, so a room can only be found by someone who has its link.

Things worth knowing:

Anyone with the full link can read and write in the room, so share it like a password.

If the link is lost, the room is lost. Nobody can recover the key, including the server.

Nothing is saved to disk. Messages live in the server's memory, and a restart wipes every room.

Names are random labels picked in your browser. They are not proof of who is typing.

The server can still see IP addresses, message timing, and message sizes.

Built with Flask and the browser's Web Crypto API. Messages use AES-GCM with a 256-bit key.
